# gost-report-skill

[![CI](https://github.com/Bbar0n234/gost-report-skill/actions/workflows/ci.yml/badge.svg)](https://github.com/Bbar0n234/gost-report-skill/actions/workflows/ci.yml)

Agent Skill для оформления студенческих работ по ГОСТ 7.32: лабораторные, курсовые, ВКР (текстовая часть), отчёты по практике, рефераты, контрольные.

Принцип: **LLM пишет только Markdown, форматирование детерминировано.** Агент согласовывает с вами структуру и генерирует содержимое; скрипт собирает .docx с правильными стилями (Times New Roman 14 pt, полуторный интервал, отступ 1,25 см, поля по ГОСТ), титульным листом вуза и автоматическим СОДЕРЖАНИЕМ. Нейросеть не трогает стили — «съехавшее оформление» исключено по построению, а `scripts/verify.py` проверяет собранный файл 18 детерминированными проверками.

## Как это выглядит

```
Вы:    Оформи отчёт по лабораторной №3 по операционным системам, вот методичка
Агент: [читает методичку] → предлагает структуру → согласовывает
       → пишет report.md → python build.py report.md → report.docx готов
```

## Установка

Скилл следует открытому стандарту [Agent Skills](https://agentskills.io) — работает в любом совместимом агенте:

```bash
git clone https://github.com/Bbar0n234/gost-report-skill.git
```

| Агент | Куда положить папку `gost-lab-report/` |
|---|---|
| Claude Code | `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`) |
| Codex CLI | `~/.agents/skills/` |
| opencode | `~/.config/opencode/skills/` |

Зависимости — слоями:

- **Слой 0 (обязательный):** `pandoc` + `pip install python-docx docxcompose` — сборка документа.
- **Слой 1 (опциональный):** LibreOffice + python-uno — автоматический пересчёт СОДЕРЖАНИЯ и счётчиков реферата. Без него содержание обновляется в Word одним нажатием (Ctrl+A → F9).

Быстрая самодиагностика: `python gost-lab-report/scripts/check_env.py`.

## Совместимость

Проверено CI-матрицей и Docker-прогонами (детали и версии — [gost-lab-report/ENVIRONMENTS.md](gost-lab-report/ENVIRONMENTS.md)):

| Платформа | Сборка .docx | Авто-СОДЕРЖАНИЕ |
|---|---|---|
| Linux (Ubuntu, Debian, Fedora) | ✅ | ✅ |
| Windows (нативно) | ✅ | Ctrl+A → F9 в Word |
| Windows + WSL | ✅ | ✅ |
| macOS | ✅ | Ctrl+A → F9 в Word |

Нестабильное или экзотическое окружение? Сборку можно гонять в контейнере (`ubuntu:24.04` + слой 0/1 из ENVIRONMENTS.md) — движку всё равно, где выполняться.

## Титульные листы

Готовые шаблоны: ГУАП (лабораторная, курсовая), СПбГЭУ (курсовая). Титульник выбирается YAML-полем `title_page`, поля подставляются из метаданных отчёта.

Нет вашего вуза? У скилла есть **wizard**: дайте агенту .docx-бланк титульника вашего вуза — он сам превратит его в шаблон с плейсхолдерами, прогонит тест-матрицу и покажет вам результат на приёмку (`gost-lab-report/WIZARD.md`). Это разовая настройка; дальше шаблон работает как встроенные.

## Границы

- Титульники подключаются только из .docx (PDF не конвертируется).
- Подписные бланки (задание, календарный план, дневник практики, отзывы) не генерируются — вкладываются вручную.
- ЕСКД-рамки и печати — вне скоупа.
- Типографика фиксирована ГОСТ 7.32; вузовские отклонения от него — ручная правка `templates/reference.docx`.

## Структура

```
gost-lab-report/
├── SKILL.md          — ядро: порядок работы, YAML, конвенции Markdown
├── PROFILES.md       — профили типов работ (структуры разделов)
├── WIZARD.md         — подключение титульника нового вуза
├── REVIEW.md         — чек-лист финальной проверки отчёта
├── ENVIRONMENTS.md   — проверенные окружения и версии
├── scripts/          — build.py, verify.py, update_fields.py, check_env.py
├── templates/        — reference.docx (стили ГОСТ) + title_pages/
└── filters/          — pagebreak.lua
```
