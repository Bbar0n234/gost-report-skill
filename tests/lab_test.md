# Цель работы

Изучить механизмы планирования процессов в ОС Linux и научиться управлять приоритетами.

# Ход работы

Для просмотра приоритетов использовалась команда `ps`. Результаты замеров приведены в таблице 1.

Таблица 1 – Результаты замеров

| Приоритет | Время, с | Загрузка CPU, % |
|-----------|----------|-----------------|
| 0         | 12,4     | 25              |
| -10       | 8,1      | 48              |

Скрипт запуска приведён в листинге 1.

Листинг 1 – Скрипт запуска

```bash
#!/bin/bash
nice -n -10 ./worker &
wait
echo "done"
```

# Выводы

Приоритет процесса напрямую влияет на распределение процессорного времени.
